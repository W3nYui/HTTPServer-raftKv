# Portable MariaDB and Connector/C++ Environment

The project will keep its existing MySQL Connector/C++ 1.1 `cppconn` API while using MariaDB LTS as the local database server. The database service remains reachable only from the local machine, and the application uses a dedicated `gomoku` account instead of a database administrator account.

Connector/C++ 1.1 is built from the MySQL official archive into `runtime/deps/mysql-connector-cpp`. This makes the legacy API available on CachyOS and Ubuntu WSL 22.04 without depending on distribution-specific availability of an obsolete development package. CMake discovers the connector through an explicit `MYSQL_CONNECTOR_CPP_ROOT` hint and normal system prefixes, and reports missing headers or libraries during configuration.

Database credentials are generated by an initialization script and stored only in the gitignored `runtime/gomoku-db.env` with restrictive permissions. `start-demo.sh` loads that file before it starts the application. README documents both CachyOS and Ubuntu WSL setup, the local-only access boundary, and the commands used to build and initialize the environment.
